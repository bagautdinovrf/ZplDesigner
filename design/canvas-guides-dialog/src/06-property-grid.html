Расстояние от краёв этикетки до рамки безопасной зоны. На печать не влияет — нужен для привязки и контроля полей. Допустимо 0–19,89 мм (0–159 dots): меньше половины короткой стороны.

Что меняется

  • Все параметры — одна плотная таблица, как редактор свойств Qt Designer.
  • Группы сворачиваются, направляющие вложены по осям; свёрнутая ось показывает значения в строке.
  • Описание выбранного свойства с допустимым диапазоном вместо постоянных пояснений.
  • Поиск по названию свойства.

Компромиссы

  • Привычно разработчикам, менее очевидно остальным.
  • Важное и редкое выглядят одинаково — нет визуальной иерархии.
  • Правка через редактор в ячейке (двойной щелчок или F2) медленнее флажков.

Реализация в Qt

  • QTreeView + QStandardItemModel; флажки — Qt::CheckStateRole.
  • Редакторы — QStyledItemDelegate с DotSpinBox; строки категорий рисует тот же делегат.
  • Описание — QLabel, обновляется по currentChanged; поиск — QSortFilterProxyModel с рекурсивной фильтрацией.
